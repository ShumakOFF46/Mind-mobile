# Workflow: Mobile Agent (AURA / beauty_mobile) ↔ Оркестратор

Зафиксировано: 2026-09-08.

## Репозитории

- **`ShumakOFF46/beauty_mobile`** — полный read/write доступ мобильного
  агента. Сюда:
  - забираются текущие файлы Flutter-приложения перед началом работы;
  - выкладываются изменённые файлы **полностью** (не диффы) после
    выполнения брифа;
  - в **корень репозитория** кладутся отчёты для оркестратора
    (`REPORT_mobile_*.md`, эскалации и т.п.) и служебные заметки вроде
    этого файла.
- **`ShumakOFF46/vb_docs`** — read-only. Источник брифов и мастер-
  документов проекта: `AGENT_RULES_orchestrator.md`, `ProjectFull.md`,
  `ProjectBeauty.md`, `ProjectChangelog.md`, `universal_dialog_engine.md`.
  Мобильный агент сверяется с этими файлами перед началом любой задачи,
  но не редактирует их напрямую — правки мастер-документов делает
  оркестратор.
- **`ShumakOFF46/VB-backend`** — read-only. Бэкенд-референс (контракты
  SSE, `app_tools.py`, `chat_blocks.py` и т.д.), когда нужно свериться
  с реальным поведением API, не полагаясь только на прозу в `vb_docs`.

## Доступ

Токены доступа к репозиториям (beauty_mobile full access, read-only на
весь проект) выдаются отдельно и не хранятся в этом файле/репозитории.

## Формат работы над брифом

1. Прочитать актуальный бриф/контекст в `vb_docs` (или получить текст
   брифа напрямую от оркестратора).
2. Свериться с чек-листом `AGENT_RULES_orchestrator.md` §3 (лимит
   300–400 строк на файл, разделение слоёв, UnknownBlock-fallback для
   новых SDUI-блоков и т.д.).
3. Забрать актуальные файлы из `beauty_mobile`.
4. Внести изменения, прогнать `flutter test` там, где применимо.
5. Запушить изменённые файлы **целиком** обратно в `beauty_mobile`.
6. Положить отчёт о проделанной работе в корень `beauty_mobile`
   (`REPORT_mobile_<тема>.md`) — что сделано, что подтверждено живым
   прогоном/тестами, какие открытые хвосты остались.

Коммит и финальный пуш в основную ветку — на усмотрение пользователя;
агент коммитит свою работу с коротким сообщением, отражающим суть
изменений.
