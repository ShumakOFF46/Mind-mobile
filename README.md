# AURA Mind

Мобильное приложение AURA Mind — часть экосистемы AURA Muza
(AI-компаньон индустрии красоты). Репозиторий создан как шаблон на
основе `beauty_mobile`: платформенные заготовки (Android/iOS/Web/...)
и базовый `pubspec.yaml`, без прикладного кода — фичи AURA Mind
разрабатываются с нуля.
